## 一、核心概念速查

| 术语 | 说明 |
|------|------|
| **平行志愿** | 同一批次可填多个志愿，系统按分数从高到低检索，一旦投出即停止检索其他志愿 |
| **顺序志愿** | 第一志愿优先；只有第一志愿未录满，才检索第二志愿（已基本淘汰，仅少数提前批保留） |
| **院校专业组** | 志愿单元=一所学校的一个专业组（组内可填6个专业偏好）；调剂只在组内 |
| **专业+学校** | 志愿单元=一个专业+一所学校的精确组合；无调剂问题 |
| **投档** | 省招办将考生档案发送给目标高校，高校看档后决定是否录取 |
| **退档** | 档案被投出后，因专业不符/不服从调剂/身体条件被高校退回；**退档后本批次其他志愿全部作废** |
| **滑档** | 所有志愿均未被投出（分数不够）；同样只能参加征集志愿 |
| **征集志愿** | 正式投档结束后，针对招生计划未完成的高校/专业再次组织填报；名额少、专业差，是"兜底"而非"机会" |

## 二、平行志愿投档全流程

```
① 分数排序：所有考生按成绩从高到低排队（同分看位次规则）

② 逐人检索：轮到某考生时，系统按志愿顺序（第1→第2→…）依次判断
   → 该院校专业组是否有名额？
   → 考生是否满足该专业组选科要求？
   → 是 → 投档，停止检索

③ 一轮投档：档案被投出后，本批次其他志愿全部失效

④ 高校录取：
   → 按考生成绩+专业偏好顺序分配专业
   → 若所填专业均满 & 不服从调剂 → 退档（⚠ 极危险）
   → 若服从调剂 → 分配至该组任意未满专业

⑤ 投档比例：
   → 平行志愿：1:1（招多少投多少，不超额）
   → 顺序志愿（少数提前批）：最高120%
```

**最大风险**：退档后无法回头。志愿顺序越靠后=保底越稳，不要把所有志愿都填"够不着"的学校。

## 三、批次结构总览

### 通用批次框架（从先到后）

| 顺序 | 批次 | 典型包含院校 | 特点 |
|------|------|-----------|------|
| 1 | **强基计划** | 39所985高校特定专业 | 需通过校测；先于提前批 |
| 2 | **综合评价批** | 部分985/211（上海/浙江为主） | 高考成绩+综合测试+学考 |
| 3 | **本科提前批A** | 军校、公安、飞行员、公费师范 | 多为顺序志愿；录取后不参与后续批次 |
| 4 | **本科提前批B** | 农村/地方专项、部分艺体类 | 省份不同差异大 |
| 5 | **国家专项计划** | 农村贫困地区考生专属985/211名额 | 分数要求略低于普通批 |
| 6 | **本科普通批** | 全部普通高校 | **最主要批次**，平行志愿 |
| 7 | **专科提前批** | 公安/定向/涉密等专科 | 少数省份设置 |
| 8 | **专科普通批** | 全部高职高专 | 平行志愿 |

> 提前批落选不影响后续批次；但一旦被提前批录取，后续批次自动退出。

## 六、退档风险与应对

| 风险类型 | 原因 | 后果 | 预防 |
|---------|------|------|------|
| **退档** | 所填专业全满+不服从调剂 | 本批次失效，只能征集 | 勾选"服从调剂"，或选专业不太热门的组 |
| **退档** | 身体条件/单科分不符合专业要求 | 同上 | 填志愿前仔细核查招生章程 |
| **滑档** | 所有志愿均未达投档线 | 同上 | 最后2-3个志愿必须填稳妥保底 |
| **调剂到不喜欢的专业** | 服从调剂但专业随机 | 录取了但专业差 | 进校后尽快了解转专业政策 |

**关键建议**：
- 志愿梯度："冲1-2个 + 稳3-4个 + 保2-3个"，保底志愿必须是100%能进的
- 院校专业组模式：组内所有专业都要确认能接受，再决定是否服从调剂
- 专业+学校模式：直接锁定专业，无调剂风险，但志愿个数要充分利用

## 七、征集志愿说明

- **触发条件**：正常投档结束后仍有招生计划未完成的院校
- **参与资格**：本批次未被录取、成绩达到批次线的考生
- **特点**：剩余名额少、高校层次偏低、热门专业基本无缘，是"最后补救"而非"弯道超车"
- **建议**：认真填好正式志愿，不要依赖征集志愿

---

## 八、新高考选科与志愿的关系

- **物理类/历史类**：选哪个首选科目，只能报对应类别的专业组
- **再选科目限制**：部分专业组要求特定再选科目（如临床医学通常要求物化生）
- **不同省份进度**：2025年全国31省均已进入新高考，老高考(文理分科)已全部成历史

> ⚠️ 选科决定了能填什么专业，是高一就要做的关键决策，不是高三才考虑的事

## 九、AI使用说明

1. **用户问"能填几个志愿"** → 查上方对应省份的"本科普通批志愿数量"
2. **用户问"退档了怎么办"** → 说清楚：退档后本批次其他志愿全失效，只能等征集
3. **用户问"要不要服从调剂"** → 分析用户情况：冲高校时建议服从（降落档风险）；对专业有强烈要求时可不服从（接受退档风险）
4. **用户问"提前批和普通批能一起参加吗"** → 可以填，但被提前批录取后自动退出普通批；提前批未录取完全不影响普通批
5. **用户问"征集志愿有没有机会"** → 有，但机会小，剩余名额往往是冷门专业/院校
