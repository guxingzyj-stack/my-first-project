# 使用提醒

- 后续如果要统一系统提示词、网页后端规则和模型回答流程，优先引用 `AI回答流程总规范`。
- 先用系统提示词约束事实边界。
- 再用分类路由提示词决定用户问题该走哪里。
- 如果命中历史数据，一定要提示“仅供参考”，不要把历史结果写成当年结果。
- 如果涉及“某学校 / 某专业多少分能不能上”，再结合 `07_录取数据/AI查数与数据使用规则` 决定什么时候查原始数据层。
